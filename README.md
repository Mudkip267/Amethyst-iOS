# Horizon Amethyst for iOS

Private build workspace for the Amethyst-inspired launcher patch. The workflow rebuilds the SwiftUI framework for arm64 iPhoneOS with Xcode 26 and pairs it with the verified engine from [Horizon iOS build 92.1](https://github.com/heyskylo/horizon-ios/releases/tag/ios-build-92.1). The complete upstream source is [heyskylo/horizon-ios](https://github.com/heyskylo/horizon-ios/tree/cf2707b035917d9f93fb7ea89ddc077396e19e96). Horizon and the iOS port retain their MIT notices.

Download Horizon-Amethyst-iOS from the workflow artifacts and sign the IPA before installing. It has a separate app identifier. Game resources are prepared from a licensed Minecraft Java Edition 26.3 installation or obtained through the port's existing setup flow. No Minecraft files or signing credentials are included.
